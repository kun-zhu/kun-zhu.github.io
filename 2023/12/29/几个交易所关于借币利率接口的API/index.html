几个交易所关于借币利率接口的API

发表于 2023-12-29 更新于 2024-08-15

币安，okx交易所有关借币的api对接和总结。

币安借币利率API接口总结

币安平台提供了多个关于借币利率的API接口，以下是对这些接口的总结。

1. 质押借币

  • com.kun.loan_scaner.service.api.BinanceApi#getLoanList(String)
    • 接口说明：查询可借币种数据 (USER_DATA)
    • 接口地址：GET /sapi/v1/loan/loanable/data
    • 实现情况：官方API已实现
    • 调用方式：
      new SpotClientImpl(API_KEY, SECRET_KEY).createCryptoLoans().loanAssetsData(parameters)
    • 参数：可传入某个币种，不传则默认返回五条数据
    • 返回：7天、14天、30天、90天、180天的利率

2. 质押借币（活期）

  • com.kun.loan_scaner.service.api.BinanceApi#getFlexibleLoanList(String)
    • 接口说明：查询活期借币可借币种数据 (USER_DATA)
    • 接口地址：GET /sapi/v1/loan/flexible/loanable/data
    • 实现情况：官方API未实现
    • 参数：可传入某个币种，不传返回143个币种的活期借币利率（测试日期：2023-12-1）
    • 返回：对应币种的活期借款利率

3. VIP借币

  • com.kun.loan_scaner.service.api.BinanceApi#getVipLoanList(String)
    • 接口说明：查询VIP借币可借币种数据 (USER_DATA)
    • 接口地址：GET /sapi/v1/loan/vip/loanable/data
    • 实现情况：官方API未实现
    • 参数：可传入某个币种，不传返回295个币种的活期借币利率（测试日期：2023-12-1）
    • 返回：活期、30天、60天的借款利率
    • 备注：VIP等级不影响活期贷款利率

4. VIP借币（查询借款利率）

  • com.kun.loan_scaner.service.api.BinanceApi#getVipFlexibleLoanList(String)
    • 接口说明：查询借款利率 (USER_DATA)
    • 请求地址：/sapi/v1/loan/vip/request/interestRate
    • 实现情况：官方API未实现
    • 参数：必须传入某个或者不超过十个的币种，不传会报错
    • 返回：对应币种的活期借款利率
    • 备注：返回的活期贷款利率可能与其他接口和币安网页不同，考虑不使用

5. 通过期货做空并买现货实现借款

  • com.kun.loan_scaner.service.api.BinanceApi#getFundingRate(String)
    • 接口说明：查询资金费率信息
    • 请求地址：/fapi/v1/fundingRate
    • 实现情况：官方API已实现
    • 调用方式：
      new UMFuturesClientImpl().market().fundingRate(parameters);
    • 参数：可提供某个交易对，不提供则返回最近更改的指定条数的交易对信息
    • 返回：对应交易对的起始时间和费率

6. 杠杆借币（全仓）

  • com.kun.loan_scaner.service.api.BinanceApi#getCrossMarginData(String)
    • 接口说明：获取全仓杠杆利率及限额 (USER_DATA)
    • 接口地址：GET /sapi/v1/margin/crossMarginData
    • 实现情况：官方API已实现
    • 调用方式：
      new SpotClientImpl(API_KEY, SECRET_KEY).createMargin().crossMarginData(parameters);
    • 参数：可传入某个币种，不传则返回308种币种的数据（测试日期：2023-12-1）
    • 返回：对应币种的杠杆借币利率

7. 杠杆借币（逐仓）

  • com.kun.loan_scaner.service.api.BinanceApi#getIsolatedMarginData(String)
    • 接口说明：获取逐仓杠杆利率及限额 (USER_DATA)
    • 接口地址：GET /sapi/v1/margin/isolatedMarginData
    • 实现情况：官方API已实现
    • 调用方式：
      new SpotClientImpl(API_KEY, SECRET_KEY).createMargin().isolatedMarginData(parameters);
    • 参数：可传入某个交易对，不传则返回576种币种的数据（测试日期：2023-12-1）
    • 返回：对应交易对（两个）的杠杆借币利率
    • 备注：注意，返回的许多利率是重复的，例如BTCUSDT和ETHUSDT都会返回USDT的借款利率，相同无意义

OKX 借贷API接口总结

OKX平台在借贷方面提供了几个关键的API接口，以下是对这些接口的总结。

1. 获取市场借币杠杆利率和借币限额

  • com.kun.loan_scaner.service.api.OkxApi#getOkxLoanList
    • 接口说明：查询所有币种的借贷利率和借贷限额
    • 请求地址：GET /api/v5/public/interest-rate-loan-quota
    • 入参：无需参数
    • 返回：所有币种的借贷利率和借贷限额

2. 获取尊享借币杠杆利率和借币限额

  • com.kun.loan_scaner.service.api.OkxApi#getOkxVipLoanList
    • 接口说明：查询所有币种的尊享借贷利率和借贷限额
    • 请求地址：GET /api/v5/public/vip-interest-rate-loan-quota
    • 入参：无需参数
    • 返回：所有币种的尊享借贷利率和借贷限额

3. 获取资金费率

  • com.kun.loan_scaner.service.api.OkxApi#getFundingRate
    • 接口说明：查询合约的资金费率
    • 请求地址：GET /api/v5/public/funding-rate
    • 入参：instId（必须，例如：BTC-USD-SWAP）
    • 返回：对应交易对的资金费率

4. 获取全部资金费率

  • com.kun.loan_scaner.service.api.OkxApi#getFundingRateByMargined
    • 接口说明：一次性查询所有币种的资金费率
    • 请求地址：GET /priapi/v5/public/funding-rate-all
    • 入参：t（时间戳），ccyType（币种类型，例如：USDT、USDC、USD）
    • 返回：所有币种的资金费率

注：目前OKEX的接口实现主要是Python的，Java的实现尚未找到，需要自行实现。
