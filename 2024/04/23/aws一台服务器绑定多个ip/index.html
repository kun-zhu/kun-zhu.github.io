AWS一台服务器绑定多个ip

发表于 2024-04-23 更新于 2024-04-24

最近使用在使用程序固定请求第三方的api，触发了第三方对“同一个IP下不同IP请求次数”的限制，需要使用多个IP访问请求，本来以为需要新购买机器，没想到朋友说AWS可以直接购买和绑定Ip到目前已有的机器。在朋友的知道下购买了IP，并绑定到了我的服务器上，并更改了我的Java代码，解决了这个问题。

AWS的EC2购买新的IP并绑定

注：之前购买的时候没有截图，先文字记录，记得下次如果再买的话补点图。

在AWS的控制台选择“网络与安全”-“弹性ip”先在右上角的“分配弹性IP地址”分配一个新的IP地址，一通默认确认下来，即可得到一个新的IP。点击这个IP地址进入到这个IP的操作页面。选择右上角的“操作”，关联此IP到现有的服务器的网卡上。复制记录下自己分配到的IP地址，即可退出IP这里的操作界面。

回到EC2对应的那台服务器上，点击对应的那台服务器，进入操作页面，点击右上角的“操作”- “联网”-“管理IP地址”，选中网卡eth0，在网卡上分配新的IP地址，并在“公有IP地址”那一栏目填上刚才操作1中记录的IP地址，保存即可。

这时候，登录此服务器，看看是否已绑定上新的IP，如果已绑定成功，就不需要操作了，如果没有新的IP出现，需要在服务器上加载一下。加载的方式可以参考这个链接：如何在Ubuntu中添加额外的IP地址，或者直接按照下面（Ubuntu 22.04）我复制的步骤的代码：
